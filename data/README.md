# Local copies of the series (optional)

A file `<name>.csv` here, with columns `t` and `value`, replaces the download or the generator for that series.
Names: `EPL`, `Sunspots`, `MackeyGlass`, `etth1`, `etth2`, `melbourne_temp`, `co2_weekly`, `elnino_monthly`,
`lorenz`, `lorenz_noisy`, `rossler`.

`EPL.csv` must be placed here: that series has no public download without a sign-in. See the main README.

All the datasets are provided in [`datasets.zip`](../datasets.zip) at the root of this repository. To use them, extract its
contents into this folder, e.g. from the repository root:

```bash
unzip datasets.zip -d data/
```
