# Condition-gated spiking neural P forecasters

Code for the paper *Restoring the firing condition: condition-gated spiking neural P models for sparse, closed-form univariate time-series forecasting*.

Everything is in one notebook, `trace_snp.ipynb`. Run top to bottom, it takes the 11 raw series, trains and fits every model, runs every statistical test and control experiment, and writes every figure and table of the paper and its supplementary material. It needs no account, token or remote storage. All results are written to a local folder.

## Models

**Proposed family.** These are spiking neural P (SNP) forecasters with an explicit firing condition:

- **ALSTM-SNP:** the learned member. It is a recurrent SNP cell with spiking, adaptive-threshold neurons, trained by surrogate gradients.
- **TRACE-SNP v1:** the closed-form member. It is a tapped delay line feeding triangular receptive fields (exactly two of M fire per delay), plus k-nearest state neurons on the recent embedding. The readout is linear in its weights, so it is fitted by one ridge solve. Selection uses exact leave-one-out residuals plus a validation block. A binary-spike version is also fitted.
- **TRACE-SNP v2:** v1 with two additions. The reference point is either the newest value or the window mean. Multi-step forecasts are either direct or iterated, chosen on validation with a margin rule.
- **TRACE-SNP-AF:** v2 with an adaptive firing condition. It chooses among triangular and Gaussian receptive fields with 2, 4 or 8 active fields, per fold and before any test data is seen.

**Baselines.**

- **Networks, all at hidden size 8:** LSTM, GRU, LSTM-SNP, BiLSTM-SNP, an attention model, Informer, Autoformer and FEDformer.
- **Closed-form and simple models:** NG-RC, DLinear, ridge AR(L), persistence and the window mean.
- **Control experiments:** an echo-type SNP reservoir, plus tuned and directly trained network variants.

## Mathematical summary

This section states the models and every mathematical result of the paper. The full proofs are in the supplementary material. Notation:

- σ is the logistic function, softplus(x) = log(1 + eˣ), and Θ is the Heaviside step.
- ⊙ is the entry-wise product.
- L is the window length (number of delays), M the number of receptive fields per delay, and C the number of state neurons.
- Each series ends in J = 5 test blocks. Test block j is preceded by a validation block 𝒱ⱼ of the same length, and every earlier point is the training set 𝒟ⱼ.

### Standing assumptions

| | Assumption |
|---|---|
| A1 (ALSTM-SNP) | α, ρ ∈ (0,1) through σ; β = softplus(·) ≥ 0; b₀ = softplus(·) + 10⁻³ > 0; u₀ = η₀ = h₀ = 0. |
| A2 (grid) | The centres are c_m = c₁ + (m−1)Δ, with c₁ = −1.1, c_M = 1.1 and Δ = 2.2/(M−1). The scaling maps the training range onto [−1, 1]. |
| A3 (ridge) | Every TRACE-SNP candidate has the penalty P = λ₀I + P′, with λ₀ > 0 and P′ ⪰ 0. |
| A4 (information set) | Every quantity used for test block j (scaling, prototypes, weights, hyperparameters, field family, multi-step mode) is computed from 𝒟ⱼ ∪ 𝒱ⱼ only. |
| A5 (independent datasets) | The 11 series are independent units for the dataset-level tests. |

### The condition-gated SNP neuron

**Definition.** A neuron has:

- a state u_t;
- a charge q_t, computed from its inputs and its previous state;
- a threshold B_t.

It fires when z_t = 𝟙[q_t ≥ B_t], and updates

  u_t = r_t·u_{t−1} + i_t − z_t·κ_t,  h_t = z_t·e_t,

with reset factor r_t, input current i_t, consumption κ_t ≥ 0 and emission e_t. Its **activity** is the share of neurons that fire.

| Result | Statement |
|---|---|
| LSTM-SNP has no firing condition | LSTM-SNP, u_t = r_t⊙u_{t−1} − c_t⊙a_t with h_t = o_t⊙a_t, is the neuron above with i_t = 0, κ_t = c_t·a_t, e_t = o_t·a_t and **B_t = −∞**. Every neuron fires at every step, so its activity is identically 1. |
| A finite threshold changes the model | A gated neuron with a finite B reproduces LSTM-SNP on every input **if and only if** B ≤ inf q_t along every trajectory, that is, if and only if its condition never fails. |
| LSTM-SNP costs as much as a dense network | Every synapse is used at every step, so no event-driven saving is possible. |

### ALSTM-SNP (the learned member)

The gate pre-activations use no self-recurrence (the recurrent matrices U have zero diagonals). The cell is:

  ñ_t = tanh(W_n x_t + U_n h_{t−1}),  o_t = σ(W_o x_t + U_o h_{t−1} + v_o⊙u_{t−1})
  ũ_t = α⊙r_t⊙u_{t−1} + n_t,  B_t = b₀ + β⊙η_{t−1}
  v_t = (ũ_t − B_t) ⊘ B_t,  z_t = Θ(v_t)
  u_t = ũ_t − z_t⊙c_t⊙B_t,  η_t = ρ⊙η_{t−1} + (1−ρ)⊙z_t
  h_t = o_t ⊙ z_t ⊙ softplus(ũ_t)

Training uses the surrogate derivative ψ(v) = γ·max(0, 1 − |v|).

| Result | Statement (under A1) |
|---|---|
| Firing trace | 0 ≤ η_t ≤ 1 − ρᵗ < 1. |
| The firing condition is well defined | b₀ ≤ B_t ≤ b₀ + β(1 − ρ^{t−1}) < b₀ + β. Hence v_t is finite, and z_t = 1 if and only if ũ_t ≥ B_t. |
| b₀ > 0 is necessary | If b₀ = 0, then v₁ is undefined. As b₀ → 0, a neuron that has not fired receives no learning signal on almost every input. |
| Unconditional boundedness | For every input sequence, bounded or not: abs(u_t) ≤ abs(ũ_t) < (1 − ᾱᵗ)/(1 − ᾱ) < 1/(1 − ᾱ), where ᾱ = max_j α_j. |
| Bounded outputs and forecasts | 0 ≤ h_t < softplus(1/(1−ᾱ)), and h_t = 0 whenever z_t = 0. Every iterated h-step forecast stays in a fixed bounded interval. |
| Bounded surrogate gradients | 0 ≤ ∂z_t/∂ũ_t ≤ γ/b₀ and abs(∂z_t/∂B_t) ≤ 2γ/b₀. |
| Silent neurons cost nothing | If z_{t,j} = 0, then h_{t,j} = 0 exactly. The recurrent synaptic operations at step t+1 are (H−1) × the number of neurons that fired at step t, per gate. |

### TRACE-SNP (the closed-form members)

**Forecast.** The forecast of x_{o+h−1} is computed from the scaled delays u_k = s(x_{o−k}), k = 1…L, as

  x̂ = anchor + s⁻¹·[ b + Σ_k a_k·u_k + Σ_k Σ_m w_{k,m}·μ_m(u_k) + Σ_c ν_c(z)·(α_c + γ_cᵀz) ],  z = (u₁,…,u_d).

- **Anchor:** v1 always uses the newest value x_{o−1}. v2 and AF choose between x_{o−1} and the window mean.
- **Pathways:** there are three kinds of neurons.
  - *Linear neurons* a_k·u_k are always active.
  - *Receptive-field neurons* use triangular fields μ_m(u) = max(0, 1 − abs(u − c_m)/Δ) (Wang–Mendel).
  - *State neurons* ν_c fire for the k_a = 4 prototypes nearest to z (k-means++ with a fixed seed). They use a normalised Gaussian kernel and Takagi–Sugeno consequents.

**Fit.** Every candidate is fitted by

  θ̂ = argmin J(θ),  J(θ) = (1/N)·‖r − Φθ‖² + θᵀPθ,  P = λ₀I + λ_s Σ_k E_kᵀD₂ᵀD₂E_k + λ_st E_stᵀE_st,

with A = (1/N)ΦᵀΦ + P and g = (1/N)Φᵀr. Here D₂ is the second-difference (curvature) operator on the field weights of one delay.

**Selection.** For block j, the chosen candidate minimises

  Crit_j = ( [ Σ_{i∈𝒟ⱼ} (e_i/(1 − H_ii))² + Σ_{v∈𝒱ⱼ} e_v² ] / (abs(𝒟ⱼ) + abs(𝒱ⱼ)) )^{1/2}.

Persistence, the window mean and ridge AR(L) are always among the candidates.

| Result | Statement |
|---|---|
| Partition of unity (A2) | Σ_m μ_m(u) = 1 on [c₁, c_M]. Exactly two fields fire (one at a centre), and finding them costs O(1) operations. |
| Piecewise-linear representation | w ↦ Σ_m w_m·μ_m is a linear bijection onto the continuous functions that are affine on each grid cell, with g(c_m) = w_m. Each delay contributes a one-dimensional function f_k(x_{t−k}). |
| Approximation rate | For an L_f-Lipschitz f, ‖f − 𝓘f‖_∞ ≤ L_f·Δ/2. For f in C², ‖f − 𝓘f‖_∞ ≤ Δ²·‖f″‖_∞/8. |
| Additive targets | For F(u) = g₀ + Σ_k g_k(u_k), the delay pathway reaches sup abs(F − F̂) ≤ (Δ/2)·Σ_k L_k. Δ = 0.147 for M = 16 and Δ = 0.071 for M = 32. |
| Curvature penalty | (D₂w)_m = Δ²·f″(ξ_m) when w samples a C² function. The null space of D₂ is the affine functions, so the penalty never shrinks a linear trend. |
| State neurons | Exactly min(k_a, C) state neurons fire, with ν ≥ 0 and Σν = 1. The state pathway is a convex combination of k_a local affine models: a first-order Takagi–Sugeno system that is linear in its weights. |
| Exact activity | With inputs inside the grid, 2L + k_a of the ML + C event neurons fire, for example 44/704 = 6.25 % at L = 20, M = 32, C = 64. Without the state pathway the share is 2/M. |
| The ridge is necessary | rank Φ ≤ p − 2L: each delay has two null directions (the partition of unity and linear reproduction), and both lie in the null space of the curvature penalty. With λ₀ = 0, J therefore has infinitely many minimisers. |
| Existence, uniqueness, stability (A3) | A ⪰ λ₀I ≻ 0, and J is 2λ₀-strongly convex. The unique solution is θ̂ = A⁻¹g, with a unique Cholesky factor, ‖θ̂‖₂ ≤ ‖g‖₂/λ₀, and smooth dependence on the data. |
| Leverages | 0 ≤ H_ii ≤ (‖φ_i‖²/N)/(λ₀ + ‖φ_i‖²/N) < 1. |
| Exact leave-one-out | The residual of the model refitted without row i equals e_i/(1 − H_ii). All N of them follow from one factorisation. The identity is exact for θ given Φ; the scaling and the k-means prototypes are not refitted per row. |
| Never worse than the fallbacks | Crit_j(selected) ≤ min over {persistence, window mean, ridge AR(L)} of Crit_j. |
| What leave-one-out estimates | For exchangeable pairs, E[(e_i/(1−H_ii))²] is the expected error on a new pair of the model fitted on N−1 pairs. Time series are not exchangeable, which is why the criterion adds the validation block. |
| No test leakage (A4) | Every test forecast is a fixed function of 𝒟ⱼ ∪ 𝒱ⱼ and of the observed window. |
| Determinism | The fit is a deterministic function of the training data. There is no seed variance, and one evaluation is the final forecast. |
| Cost of the fit | With at most q = 1 + 3L + k_a(d+1) non-zeros per row, a fit costs O(Nq² + p³ + Np²), with no iterative optimisation. |
| The 25 % margin (v2) | v2 iterates if and only if R_it ≤ 0.75·R_dir. When both modes are equally good and log(R_it/R_dir) ~ 𝒩(0, s²), it iterates with probability Φ(log 0.75 / s): 0.2 % for s = 0.1 and 7.5 % for s = 0.2. An iterated forecast costs h one-step evaluations. |

**Parameter counts.** The model has p = 1 + L + LM + C(d+1) fitted parameters. Per forecast, only these are active:

- p_act = 1 + 3L + k_a(d+1) for the triangular condition;
- p_act = 1 + (k+1)L + k_a(d+1) for a k-field Gaussian condition.

### What a firing condition removes (Gaussian fields, TRACE-SNP-AF)

The Gaussian fields have width wΔ, and the k fields nearest to u fire.

| Result | Statement |
|---|---|
| n-th nearest centre | δ₍ₙ₎ ≥ (n−1)Δ/2. |
| Upper bound on the dropped activation | ε_k(u; w) ≤ Σ_{n>k} exp(−(n−1)²/(8w²)). For w = 1 the bound is 1.124 at k = 2, 0.193 at k = 4 and 3.8·10⁻⁴ at k = 8. |
| Total dense activation | abs(S_w(u) − √(2π)·w) ≤ √(2π)·w · 2e^{−2π²w²}/(1 − e^{−2π²w²}). The relative error is below 6·10⁻⁹ for w ≥ 1. |
| Lower bound | At the midpoint between two centres, two fields remove exactly 2Σ_j exp(−(2j+1)²/(8w²)). That is ≥ 0.742 (29.6 % of the dense activation) for w = 1, and ≥ 61 % for w = 2. |
| Gated against dense forecasts | For the same weights, abs(F_dense − F_k) ≤ ε̄_k(w)·Σ_k ‖w_k‖_∞. The same bound holds for the difference in RMSE. |
| Eight fields reproduce the dense basis | For w = 1 the gap is at most 0.04 % of Σ‖w_k‖_∞ at k = 8, against a factor of 1.12 at k = 2. This is consistent with the measured RMSE ratio of 0.996 for k = 8. |
| Guarantees of the adaptive condition | On every fold, TRACE-SNP-AF has the following properties: (1) its criterion is within a factor 1+τ of the best candidate; (2) it is within the same factor of the TRACE-SNP v2 choice; (3) no candidate within that tolerance has fewer firing neurons; (4) at most 8L + k_a event neurons fire; (5) the choice uses the training and validation data only. |
| Activity of TRACE-SNP-AF | (kL + k_a)/(ML + C). This is never above the dense family, and it equals v2's activity when the triangular family is chosen. |

### Operations and energy

| Result | Statement |
|---|---|
| Exact counts (TRACE family) | MAC = 2L + L + kL + kL·𝟙[Gauss] + (Cd + k_a + k_a(d+1))·𝟙[state]. AC = L·𝟙[mean anchor] + L·𝟙[difference encoding]. |
| Recurrent networks | A cell with G gates and H units needs ≈ G·H(H+1)·L MACs per window. With H = 8 that is 288L for the LSTM and LSTM-SNP and 216L for the GRU. |
| Members and ensembles | The cost of a forecast averaged over n members is n times the cost of one member. The networks use n = 60 and the closed-form models n = 1. |
| Benchmark overhead | If a call costs E(n) = E₀ + n·e₁, the energy per forecast is e₁ + E₀/n. Implementations measured with different batch sizes therefore differ even when their arithmetic is identical. Operation counts are the architectural comparison. |

### Uncertainty of the learned delay functions

| Result | Statement |
|---|---|
| Identification | The centred delay function f̃_k is invariant to every null direction of Φ, so it is determined by the forecast function. |
| Sandwich covariance | Cov(θ̂) = (σ²/N)·A⁻¹((1/N)ΦᵀΦ)A⁻¹, and Var(f̃_k(u)) = ℓ̃_k(u)ᵀ·Cov(θ̂)·ℓ̃_k(u). |
| Combining refits | Var = E_j[se_j²] + Var_j[f̃_k⁽ʲ⁾]. The plotted pointwise 95 % band is f̄_k ± 1.96·(mean se² + between-refit variance)^{1/2}. |

### Statistics over the 11 datasets

**Score.** S_{m,d} is the geometric mean, over the 18 (lag, horizon) problems of dataset d, of model m's RMSE relative to a reference.

| Result | Statement |
|---|---|
| Properties of the score | The score is invariant to shifting and rescaling a series. Ratios of scores do not depend on the reference model. Ranks use one observation per dataset. |
| Friedman and Iman–Davenport | F_F = (N−1)χ²_F / (N(k−1) − χ²_F). The Nemenyi critical difference is CD = q_α·√(k(k+1)/(6N)). For k = 16, N = 11 and χ²_F = 86.28: F_F = 10.96 on (15, 150) degrees of freedom, and CD = 6.96. |
| Holm | Holm's step-down procedure controls the family-wise error at α for valid p-values, under any dependence. |
| Power ceiling with N = 11 | The exact two-sided Wilcoxon p-value is at least 0.00098 with 0 losses, 0.0020 with 1 and 0.0049 with 2. This bounds what any Holm-corrected comparison over 15 rivals can reach. |
| Bayesian signed-rank | Each posterior probability is an average of 50,000 draws, so its Monte Carlo standard error is ≤ 0.0022. |

## How to run

**Full experiment:**

1. Open `trace_snp.ipynb` on a GPU machine.
2. Unzip `datasets.zip` into `data/`.
3. Run all cells.

Cell 7 (network training) and cells 21–23 (the control networks) take most of the time. Every long cell saves its progress continuously and stops cleanly when `TIME_BUDGET_H` (cell 0, 11 h by default) is reached. To continue, run all cells again: finished lags, folds and seeds are read back from `results/` and are not retrained.

**Smoke test:**

```
SMOKE=1 jupyter nbconvert --to notebook --execute trace_snp.ipynb --output smoke_run.ipynb
```

This uses 3 seeds, 3 epochs, lags 1 and 5, and the last 400 points of each series. All outputs carry the suffix `_smoke`, so they never mix with real results.

**Useful settings in cell 0:**

| Setting | Effect |
|---|---|
| `DATASETS_TO_RUN = ['MackeyGlass', 'lorenz']` | run a subset of the datasets |
| `MODELS_TO_RUN = ['ALSTM-SNP', 'gru_39']` | train only some of the networks |
| `RUN_TRAINING = False` | train nothing and only rebuild the analysis from `results/` |
| `FRESH_START = True` | delete and retrain the runs that this session starts |
| `RESULTS_DIR`, `DATA_DIR` | environment variables that move the two folders |

## Reproducibility

- **Network seeds:** every network is trained with seeds 0–59 on every fold. The reported forecast is the mean over the 60 seeds.
- **Closed-form members:** they have no seeds. Their fits are deterministic up to floating-point summation order on the GPU.
- **Training precision:** fp32 throughout (`AMP_DTYPE = None`, `ALLOW_TF32 = False`).
- **Test blocks:** they are used only for the reported scores. Every choice of configuration is made on the training rows and the validation blocks.
